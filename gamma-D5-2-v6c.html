Γ(D₅, 2) — Token Graph Explorer

What is this?

This app shows the complete token graph Γ(D₅,2): all ways to place 2 tokens on the 5-node D₅ tree, connected by single-step token moves. There are 10 states and 12 edges.

The D₅ tree

Trunk 1–2–3 with branch leaves 4 and 5 attached to node 3. Rooted at 1.

Edges: e₁={1,2}, e₂={2,3}, e₃={3,4}, e₄={3,5}.
Subtrees: T_{e₁}={2,3,4,5}, T_{e₂}={3,4,5}, T_{e₃}={4}, T_{e₄}={5}.

State layout

Each state {i,j} (tokens at nodes i and j, i<j) is drawn at grid position (i,j). Trunk-edge moves (e₁,e₂) are solid teal lines — unit steps on the grid. Branch-edge moves (e₃,e₄) are dashed red lines — they leave the grid.

Three modes

InspectClick any state to see its bit-string, height vector η, and distances to all other states.
DistanceClick two states X and Y to compute d(X,Y) = Σ|η_e(X)−η_e(Y)| with full breakdown, and see the full 10×10 distance matrix.
GeodesicClick source then target to highlight a shortest path and step through it move by move.

Key facts

Diameter = 5, attained by A=11000 and B=00011 (tokens at {1,2} vs {4,5}).
η(X)=(1,0,0,0), η(Y)=(2,2,1,1), d(X,Y)=|1−2|+|0−2|+|0−1|+|0−1|=5.

The formula d(X,Y)=Area_{D₅}(X,Y)=Σ_e|η_e(X)−η_e(Y)| is verified for all 45 pairs by BFS.

Color coding

Distance matrix cells are colored by value: d=1, d=2, d=3, d=4, d=5+. Each cell also shows the number of shortest paths in parentheses.

Holographic strip — visual components

The middle panel shows the Dn holographic strip: a 2D visual encoding of the height vectors η(X) and η(Y).

Trunk rectangle (left block): each column corresponds to a trunk tree edge ei for i = 1, …, n−3. The height of the filled region in column i equals ηei(X) = Σj=i+1n xj — the number of tokens on the far side of the cut defined by ei. These are suffix sums along the trunk. The area between the two step-function curves (teal for A, red for B) equals the trunk contribution to d(A,B).

Branch block (right, detached): two separate cells for the branch edges en−2 and en−1. Their values are simply xn−1 and xn ∈ {0,1} — the raw token bits on the two branch leaves — because the branch subtrees are singletons (each contains exactly one node). A thick purple border marks a branch cell when it contributes to the area.

Cell colors: teal = X only (counts toward area); red/pink = Y only (counts toward area); purple/lavender = both A and B (cancels, not in area); beige = neither.

The total distance d(A,B) = trunk Σ + branch Σ is shown explicitly below the grid, split into the two contributions.

Distance coloring in the matrix: d=1, d=2, d=3, d=4, d=5.
