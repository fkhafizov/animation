# Q



Let $N_0$, $N_1,\dots,N_K$ denote number of $0$s, $1$s, $\dots$ $K$s in all permutations $S_N$, $N=N_0 + N_1 + \dots + N_K$,  generated from
let  $e=(0^{N_0}1^{N_1}\dots K^{N_K})$ using adjacent transpositions $(i, i+1)$. Let us denote the corresponding graph as $G$.

The diameter of $G$ is $d(x^*,e)$ where $x^*=(K^{N_K} \dots 1^{N_1} 0^{N_0} )$.

Is there a standard name for the graph $G$?

Give me a formula for the number of vertices $|V|$ and the number of edges $|E|$ of $G$.


# A

This is an elegant question about the combinatorial structure of multiset permutations!

## Standard Name

The graph $G$ is commonly called the **bubble sort graph on multiset permutations** or the **Cayley graph of multiset permutations** under adjacent transpositions. In some literature, it's also referred to as:

- The **weak (Bruhat) order on multiset permutations**
- The **permutohedron graph for multisets**
- The **adjacent transposition graph**

When all $N_i = 1$ (no repetitions), this reduces to the classical permutohedron, which is the Cayley graph of the symmetric group $S_N$ generated by adjacent transpositions.

## Formulas

### Number of Vertices $|V|$

The vertices correspond to distinct permutations of the multiset, given by the multinomial coefficient:

$$|V| = \frac{N!}{N_0! \, N_1! \cdots N_K!}$$

### Number of Edges $|E|$

To count edges, note that two permutations are adjacent if they differ by swapping adjacent elements with **different** values. Using the handshaking lemma and symmetry:

$$|E| = \frac{N!}{2N \cdot N_0! \, N_1! \cdots N_K!} \left(N^2 - \sum_{k=0}^{K} N_k^2\right)$$

This can be rewritten more compactly as:

$$|E| = \frac{N! \sum_{0 \leq i < j \leq K} N_i N_j}{N \cdot N_0! \, N_1! \cdots N_K!}$$

## Analogy

Think of this like organizing colored balls on a line where you can only swap adjacent balls. The multinomial coefficient counts how many distinct arrangements exist, while the edge formula counts how many "single swap" moves connect these arrangements—which depends on how often different colors sit next to each other across all possible arrangements.

The term $\sum_{i<j} N_i N_j$ counts pairs of different colors, weighting the connectivity: more diverse multisets have more edges!
