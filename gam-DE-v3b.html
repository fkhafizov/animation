Γ(Dₙ/Eₙ, k) — Token Graph Explorer v3

What is this?

Choose a tree type (D or E), enter n and k, press Start. The app builds Γ(T,k): all C(n,k) ways to place k tokens on the n-node Dynkin tree T, connected by single token moves along tree edges.

The Dₙ tree (n ≥ 4)

Trunk 1–2–…–(n−2) with two branch leaves (n−1) and n both attached to node (n−2). Trunk edges e₁,…,e_{n-3}; branch edges e_{n-2}, e_{n-1} with singleton subtrees.

The Eₙ tree (n ∈ {6,7,8})

Trunk 1–2–…–(n−1) with one branch leaf n attached to interior node b = ⌊n/2⌋ (b=3 for E₆, b=4 for E₇, b=4 for E₈). Trunk edges e₁,…,e_{n-2}; one branch edge e_{n-1} with singleton subtree {n}.

Height vector η(X)

For each edge e, η_e(X) = #{tokens in Tₑ}. The holographic distance formula d(X,Y) = Σ_e |η_e(X)−η_e(Y)| holds for any tree T, verified by BFS for all pairs.

Graph size

|V| = C(n,k), diam = k(n−k)−1 for Dₙ; Eₙ diameter is computed by BFS.

Three modes

InspectClick any node → bit-string, η(X), distances to all states.
DistanceClick X then Y → d(X,Y) with η-breakdown and full distance matrix.
GeodesicClick source then target → shortest path, step-by-step.

Holo button

Draws a (n−1)×k height-vector rectangle next to every node. Trunk cells teal, branch cells red-tinted.
