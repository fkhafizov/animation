3-Consecutive-Cycle Graph G₃(k,n) Diameter

|V|, |E|, and D = diam(G₃(k,n)) over ranges of k (zeros) and n (word length).
Plot:

Help

k = number of 0 bits in the binary word.
n = length of the word (number of positions). Valid vertices satisfy 0 ≤ k ≤ n.

Formulas (for G₃(k,n) as in your spec):

|V| = C(n, k)
|E| = (2n − 3) · C(n − 2, k − 1)   for n ≥ 3
D = diam(G) = ⌈ k(n − k) / 2 ⌉

Inputs: integers with kmin ≤ kmax, nmin ≤ nmax, and k ≤ n for each cell. Invalid pairs are omitted from the surface (shown as gaps).

3D plot: when both k and n vary over ranges, x-axis = n, y-axis = k, z-axis = selected quantity. Drag to rotate; scroll to zoom.

2D plot: if kmin=kmax (fixed k), the plot is a curve vs n; if nmin=nmax (fixed n), the plot is a curve vs k. If both are fixed, a single point is shown.
