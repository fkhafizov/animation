# A

Here’s a clearer version of the comment and where the ambiguity shows up.

---

**What “conflicting labels in cells” means**

Imagine we tried to label each cell in the rectangles with “which adjacent swap (transposition) happens here” when we sort P to E by bubble sort.

- In the **2- or 3-element** case (e.g. only 0,1,2), there is essentially a unique way to assign transpositions to cells so that “this cell = this swap.” So each cell gets a single, well-defined label.
- In the **4-element** case (0,1,2,3), there can be **several different minimal sequences** of adjacent swaps that all take P to E. If we try to assign “which swap” to “which cell,” then:
  - One minimal sequence might say: “this cell corresponds to swap σₐ.”
  - Another minimal sequence might say: “this same cell corresponds to swap σᵦ” (a different transposition).
  So the **same cell** could get **different labels** depending on which sorting sequence we use. That’s the “conflicting labels in cells”: the label is not uniquely determined by the cell.

So the comment is about this **theoretical** labeling (transposition ↔ cell). Our app doesn’t actually draw such labels; we only draw the P and E paths and the area between them. The issue is that **if** we tried to add that kind of labeling, it would be ambiguous.

---

**Does this happen in a specific rectangle (R1, R2, or R3) or in any?**

It **can happen in any of R1, R2, or R3**, not only in one of them.

Reason:

- The braid relations (e.g. σᵢ σᵢ₊₁ σᵢ = σᵢ₊₁ σᵢ σᵢ₊₁) allow different minimal swap sequences for the same permutation.
- Those different sequences can “distribute” swaps differently across the three levels (3 vs rest, 2 vs {0,1}, 1 vs 0). So:
  - One minimal sequence might make a certain cell in **R3** correspond to a given transposition.
  - Another minimal sequence might make that **same cell in R3** correspond to a different transposition (or the “same” swap might appear in R2 or R1 in the other sequence).
- The same kind of reassignment can occur for cells in **R2** or **R1**: a cell that in one sequence is “labeled” by one transposition can, in another minimal sequence, be associated with a different transposition or with swaps that live in another rectangle.

So the ambiguity is **global** (it comes from having several minimal sort sequences); it can show up when we try to assign transpositions to cells in **any** of the three rectangles, not only in one fixed rectangle.

# Q

Here is a small example where the same cell gets different “labels” in two different minimal sort sequences.

---

## Example: P = [3, 1, 0, 2], E = [0, 1, 2, 3]

So we have one of each letter: k = n = m = t = 1.  
E = [0, 1, 2, 3], P = [3, 1, 0, 2].  
d(P, E) = 4 (four adjacent swaps in any minimal sequence).

Rectangles:

- **R3**: 1×3 (track 3 vs {0,1,2})
- **R2**: 1×2 (track 2 vs {0,1})
- **R1**: 1×1 (track 1 vs 0) → **a single cell**

So R1 has exactly one cell. We will show that this **one cell** is “filled” by **different transpositions** in two different minimal sequences.

Use τ₁ = swap positions 1–2, τ₂ = swap positions 2–3, τ₃ = swap positions 3–4.

---

### Minimal sequence A (bubble 0 left)

| Step | Swap | Result        | Which rectangle? |
|------|------|---------------|-------------------|
| 1    | τ₂   | [3, 0, 1, 2]  | Swap 0 and 1 → in “word without 3,2” we move 0 vs 1 → **R1** |
| 2    | τ₁   | [0, 3, 1, 2]  | Swap 0 and 3 → 3 moves right → **R3** |
| 3    | τ₂   | [0, 1, 3, 2]  | Swap 1 and 3 → 3 moves right → **R3** |
| 4    | τ₃   | [0, 1, 2, 3]  | Swap 2 and 3 → 3 moves right → **R3** |

So in A, the **only** step that “belongs” to R1 is **step 1**, and it is **τ₂**.

So in sequence A we assign: **R1’s single cell = τ₂**.

---

### Minimal sequence B (bubble 3 right first)

| Step | Swap | Result        | Which rectangle? |
|------|------|---------------|-------------------|
| 1    | τ₁   | [1, 3, 0, 2]  | Swap 1 and 3 → 3 moves right → **R3** |
| 2    | τ₂   | [1, 0, 3, 2]  | Swap 0 and 3 → 3 moves right → **R3** |
| 3    | τ₁   | [0, 1, 3, 2]  | Swap 1 and 0 → in “word without 3,2” we move 0 vs 1 → **R1** |
| 4    | τ₃   | [0, 1, 2, 3]  | Swap 2 and 3 → 3 moves right → **R3** |

So in B, the **only** step that “belongs” to R1 is **step 3**, and it is **τ₁**.

So in sequence B we assign: **R1’s single cell = τ₁**.

---

## The ambiguity

- **Same rectangle**: R1 (the 1×1 rectangle).
- **Same cell**: the only cell in R1.
- **Sequence A** labels that cell with **τ₂** (swap at positions 2–3).
- **Sequence B** labels that cell with **τ₁** (swap at positions 1–2).

So the **same geometric cell** gets **two different transposition labels** depending on which minimal sort we use. That is exactly the “conflicting labels in cells” phenomenon: the label (which transposition) is not uniquely determined by the cell. With 4 element types, the braid relations allow different minimal sequences that “assign” different swaps to the same step in the same rectangle, hence to the same cell.
